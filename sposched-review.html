⚽ PeakStamp → SS ゴール一括登録

動画優先

PeakStampで確認済みの複数ゴールをTESTの試合・選手と照合してまとめて登録します。不確かな試合・選手は人が選択して修正し、最後に一覧でまとめて承認します。

本番のSSは読み取り専用です。 テスト環境を明示的に選んだ場合のみ、人が確認したゴールを1件ずつプレビュー・送信できます。試合終了は、登録済みスコアを確認したうえでTESTのみ実行できます。オウンゴールの更新は対象外です。

1. このプロジェクトのゴール

PeakStampで今回読み込んだ全動画の確定済みゴールを自動集約します。1本ずつ選ぶ必要はありません。各ゴールの動画名と時刻はそのまま保持します。

対象動画を確認・変更する（通常は不要）

古い保存データは動画のファイル更新日で仮グループ化します。撮影日とは限らないので、同じ開催日の動画か確認し、1回だけプロジェクトとして保存してください。

2. Shoot Sunday当日の試合／選手名簿を読み込む

SSアプリから直接読み込む（おすすめ）

Cloudflareに設定したBRIDGE_TOKENを入力すると、SSのイベント一覧と試合・得点・選手情報を取得できます。APIキーは入力しないでください。パスワードは保存されません。

本番環境から読み取ります。書き込み操作は利用できません。

手元に保存したSSのJSONファイルから読み込む（従来方式）

SS連携が使えないときは、保存済みのJSONを読み込むこともできます。

またはJSONを貼り付ける

⚠ 前回の送信結果を確認してください（テストSSのみ）

書き込みが完了しても通信が切れた可能性があります。このイベントの次の書き込みは、安全を確認するまで禁止しています。 自動再送は行いません。

3. 動画ゴールをまとめてSSへ

TEST ONLY

動画に最初に付けた試合番号 #1、#2…をSSの試合枠に紐付けます。3位決定戦・決勝戦も先に番号でまとめられます。対戦チームが未確定の試合は入力内容を保持して送信保留にします。表示はアシスト → 得点者。各ゴールの確認チェックは不要です。

以下の新規ゴールだけをTEST環境に登録します。保留・重複候補は含めません。

登録は1件ずつ実行・照合します。途中エラー時は停止し、自動再送しません。

4. スコアを確認して試合終了

TEST ONLY

先にその試合のゴールを登録してください。SSのスコアが実際の最終スコアと一致したら、1試合ずつ終了します。準決勝を終了すると3位決定戦・決勝の対戦情報を更新します。

点数はSS登録済みゴールから算出します。違う場合は不足・重複ゴールを修正してください。終了済みの結果の変更はここでは行いません。

詳細編集（必要なゴールのみ）

選手・試合などの選択を直したら、上の「一括登録の一覧へ戻る」からまとめて確認できます。以下の個別チェック欄は従来の登録方法用で、一括登録では不要です。

実況の対戦カードと当日の選手名簿から試合・得点者・アシストを初期選択します。動画にゴールがなくても、手動で新規追加できます。 選手と試合を確認して登録してください。

動画がない場合の新規ゴール登録

テストSSの試合を選んで、得点者・アシストを手入力できます。追加したゴールは下の一覧に並び、一括登録にも含められます。

試合スコアを修正する場合（任意）

得点集計の見逃しを考慮して、ゴール件数からスコアを勝手に決めません。試合の得点を更新する場合にだけ選択し、明示的に確認します。未選択ならゴール登録のみ。

4. Shoot Sunday登録前の最終データ

まだ送信していません。新規得点登録・既存得点の修正候補・試合結果の変更をJSONとして確認できます。record_goal と patch_goal は、テスト用SSに直接読み込んだ場合だけ、下の専用画面から1件ずつ確認して送信できます。本番SSには送信しません。

このJSONは記録・確認用です。テストへの反映は下の専用操作から1件ずつ行います。ChatGPTのMCP接続は不要です。

5. TEST ONLY SSテスト環境への登録

得点者と試合を確認したゴールだけ、テストSSへ書き込みます。本番SSへの書き込みは無効です。 試合結果の更新とオウンゴール修正は対象外です。

複数ゴールをまとめて確認・登録

登録するゴールを選んで一括プレビューしてください。実際のAPI書き込みは、承認後に1件ずつ順番に実行・照合します。


   
   
   
途中でエラー・通信切断が起きた場合はその場で停止します。自動で再試行しません。SSの最新データを取得してから再開してください。
