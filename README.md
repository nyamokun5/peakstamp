# PeakStamp — Audio Highlights

> Hear the hype. Mark the moment.

iPhoneの写真ライブラリに残った複数の試合動画を、**スマートフォンのブラウザ内だけで音声解析**し、YouTubeコメント用タイムスタンプを生成します。

## MVPでできること

- MOV / MP4 / M4Vの動画を**最大12本まで一度に複数選択**（アップロード不要）
- 動画の追加、並べ替え（↑↓）、削除、動画ごとの解析状況を表示
- 音声の音量上昇からハイライト候補を抽出
- 検出感度・件数・盛り上がりの何秒前を示すか調整
- 動画を再生して候補を確認、時刻・説明の編集、除外・削除
- 単一動画では従来どおりYouTubeの元動画向けタイムスタンプをコピー。複数動画でも**元の各動画ごとのタイムスタンプ**を表示し、ファイル単位でコピー

## 自動ハイライト動画（新機能）

音声検出後に「＋ キープする」を押した見どころだけを自動で切り抜き・結合します。

- 冒頭に **5秒のタイトルカード** を挿入。初期値は **GOALS!**、HIGHLIGHTS! / BEST PLAYS! も選択可能。文字は自由に変更でき、**フォント4種類・文字サイズ60〜150%**も選択できます。
- デフォルトでは歓声のあと**1.5秒程度静かな音量が続いた位置＋3秒**で切り抜きます。静寂が見つからない場合は固定秒数（初期16秒）に戻し、固定モードも選べます。近い候補は統合して重複を防ぎます。
- **動画ごとの時系列**で切り抜き、動画一覧の順番に連結。元の試合音声を残し、**映像はシーン間で0.3秒のクロスディゾルブ**にします。音声は同じ位置で切り替えます。
- **MP4（H.264 / AAC）** を端末内で生成してプレビュー・保存します（最大約3分の試作制限）。
- 高画質1080p・30fps（10Mbps）または標準720p・30fps（4.5Mbps）を選択可能。元動画より解像度を上げません。
- シーンの「▶ 確認」でその場再生。「＋ キープする」→「✓ キープ済み」に切り替え、キープしたシーンを明確に表示します。検出直後はすべて未選択です。
- iPhoneではMP4作成後の「iPhoneに保存・共有」から共有シートを開き、「ビデオを保存」または「ファイルに保存」を選びます。通常のMP4ダウンロードと別タブ表示も用意しています。
- MP4出力失敗時のエラーメッセージを表示します。
- 縦型変換、BGM、ロゴ、テロップは追加しません。

**注意：** ファイル形式・ブラウザのWebCodecs対応・iPhoneのメモリにより書き出しに失敗する可能性があります。まず短い動画で実機検証してください。音声検出・タイムスタンプ作成は従来どおり独立して使えます。

## iPhoneで使う

GitHub Pages公開後、iPhoneのSafariで **https://nyamokun5.github.io/peakstamp/** を開きます。

1. 「複数の動画をまとめて選択」から動画を選ぶ（順番変更や追加も可能）
2. 「音声を解析する」をタップ（各動画を1本ずつ解析）
3. ピーク候補を再生確認して、使う場面の「＋ キープする」を押す。元動画ごとの時刻をコピーできます。
4. 動画編集する場合は、切り取り方法・タイトルの文字／フォント／サイズを調整し、「ハイライト動画を作成する」をタップ
5. 完成したMP4を再生し、iPhoneに保存。YouTube用タイムスタンプも従来どおりコピー可能

**YouTubeにアップロードするものと、解析する動画を同じ長さ・同じ開始位置にしてください。**
動画をトリミングすると時刻がずれます。

## 技術・プライバシー

- 静的HTML + CSS + JavaScript（APIキー / ログイン / DB / サーバー不要）
- mediabunny 1.61.3 を初回にCDNからダウンロード。WebCodecsで動画の音声を逐次デコード
- 動画ファイル自体はCDNにもGitHubにも送信しない
- 音声を0.25秒ごとに集計して、直前との音量差・ピーク強度を採点
- **音量の上昇のみを検出**。歓声、風、雑談、大声の指示などは区別しません
- iPhone Safariと実際の大型MOV / MP4ファイルでの実機検証はまだ必要です
- Safariを閉じると解析が中断します。解析中はアプリを前面に

## 2026-10-12 不具合対応 / QA

1. 従来の出力解像度960x540/15fps/2.4Mbpsを改善。高画質1080p/30fps/10Mbps、標準720p/30fps/4.5Mbps。
2. 候補の確認は上部へジャンプせず、選んだシーンの直下にプレイヤーを開く。選択済み一覧も表示。
3. MP4書き出し成功後、iPhoneネイティブ共有（Web Share API）、ファイルリンク、別タブ表示で保存。以前はエラー欄が hidden のままという不具合も修正。
4. 構文チェック、シーン抽出と画質設定のロジック検証、保存成功・失敗の画面制御をモック環境で確認済み。

**未検証:** 実際のiPhone Safariで1080p動画をエンコードしてMP4を写真／ファイルアプリに保存できるか。書き出しに失敗した場合はアプリ内に表示されるエラーを共有してください。高画質で重い場合は標準720pで短い動画を試してください。

## 複数動画版について

- 解析済みのファイルは、さらに動画を追加しても再解析不要。感度を変更した場合は各動画の保存済み音声データから候補を再計算します。
- 選択した見どころだけが結合されます。**元動画を丸ごと連結するモードではありません。**
- 動画ごとに独立した候補時刻を管理し、動画の並び順に従って1つのMP4にします。違う縦横比は先頭の採用動画に合わせて黒帯で収め、引き伸ばしません。
- 音声はAAC・48kHz・2chへ統一します。**音声付き動画のみ**が対象です。動画そのものは端末の外へ送信しません。
- 大きい動画を複数読み込んだ場合、特に高画質の書き出しはiPhone Safariのメモリ制限を受けることがあります。完成動画は当面3分以内です。
- 2026-10-12時点：JavaScriptの構文チェックと単体テストを確認しました。実際のiPhoneで異なる複数MOV/MP4をつないで正常保存できるかは、実機テストが必要です。

## 2026-10-12 第3版

- YouTubeのタイムスタンプは**元の各動画ごとの時刻**。一括一覧と、各動画の「この動画の時刻をコピー」ボタンを用意。
- 候補は初期状態で未選択。「＋ キープする」を押すと緑色の「✓ キープ済み」に変わり、編集動画へ採用。
- 切り取り終点は音声ピークの後に1.5秒静かな状態が続いた後、さらに余韻3秒を初期値に。固定秒数モードへの切替可能。
- **各シーン間の映像に0.3秒（30fpsで9フレーム）のクロスディゾルブ**。元音声はその時点で切り替え。
- 冒頭5秒の文字フォントを4種類から選択し、サイズを60〜150%で調整（横幅を超えないよう自動縮小）。
- 構文検査と音量終了位置・素材別時刻・選択状態・トランジション時間の単体テストを実施。実際のiPhone MOV/MP4での最終的な動画・音声出力は別途実機確認が必要。
