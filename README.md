# PeakStamp — Audio Highlights

> Hear the hype. Mark the moment.

iPhoneの写真ライブラリに残った複数の試合動画を、**スマートフォンのブラウザ内だけで音声解析**し、YouTubeコメント用タイムスタンプを生成します。

## MVPでできること

- MOV / MP4 / M4Vの動画を**最大12本まで一度に複数選択**（アップロード不要）
- 動画の追加、並べ替え（↑↓）、削除、動画ごとの解析状況を表示
- 音声の音量上昇からハイライト候補を抽出
- 検出感度・件数・盛り上がりの何秒前を示すか調整
- 動画を再生して候補を確認、時刻・説明の編集、除外・削除
- 単一動画では従来どおりYouTubeの元動画向けタイムスタンプをコピー。複数動画でも**元の各動画ごとのタイムスタンプ**を表示し、ファイル単位でコピー

## 自動ハイライト動画（新機能）

音声検出後に「＋ キープする」を押した見どころだけを自動で切り抜き・結合します。

- 冒頭に **5秒のタイトルカード** を挿入。初期値は **GOALS!**、HIGHLIGHTS! / BEST PLAYS! も選択可能。文字は自由に変更でき、**フォント4種類・文字サイズ60〜150%**も選択できます。
- デフォルトでは歓声のあと**1.5秒程度静かな音量が続いた位置＋3秒**で切り抜きます。静寂が見つからない場合は固定秒数（初期16秒）に戻し、固定モードも選べます。近い候補は統合して重複を防ぎます。
- **動画ごとの時系列**で切り抜き、動画一覧の順番に連結。元の試合音声を残し、**映像はシーン間で0.5秒のクロスディゾルブ**にします。音声は同じ位置で切り替えます。
- **MP4（H.264 / AAC）** を端末内で生成してプレビュー・保存します（最大約3分の試作制限）。
- 高画質1080p・30fps（10Mbps）または標準720p・30fps（4.5Mbps）を選択可能。元動画より解像度を上げません。
- シーンの「▶ 確認」でその場再生。「＋ キープする」→「✓ キープ済み」に切り替え、キープしたシーンを明確に表示します。検出直後はすべて未選択です。
- iPhoneではMP4作成後の「iPhoneに保存・共有」から共有シートを開き、「ビデオを保存」または「ファイルに保存」を選びます。通常のMP4ダウンロードと別タブ表示も用意しています。
- MP4出力失敗時のエラーメッセージを表示します。
- 縦型変換、BGM、ロゴ、テロップは追加しません。

**注意：** ファイル形式・ブラウザのWebCodecs対応・iPhoneのメモリにより書き出しに失敗する可能性があります。まず短い動画で実機検証してください。音声検出・タイムスタンプ作成は従来どおり独立して使えます。

## iPhoneで使う

GitHub Pages公開後、iPhoneのSafariで **https://nyamokun5.github.io/peakstamp/** を開きます。

1. 「複数の動画をまとめて選択」から動画を選ぶ（順番変更や追加も可能）
2. 「音声を解析する」をタップ（各動画を1本ずつ解析）
3. ピーク候補を再生確認して、使う場面の「＋ キープする」を押す。元動画ごとの時刻をコピーできます。
4. 動画編集する場合は、切り取り方法・タイトルの文字／フォント／サイズを調整し、「ハイライト動画を作成する」をタップ
5. 完成したMP4を再生し、iPhoneに保存。YouTube用タイムスタンプも従来どおりコピー可能

**YouTubeにアップロードするものと、解析する動画を同じ長さ・同じ開始位置にしてください。**
動画をトリミングすると時刻がずれます。

## 技術・プライバシー

- 静的HTML + CSS + JavaScript（APIキー / ログイン / DB / サーバー不要）
- mediabunny 1.61.3 を初回にCDNからダウンロード。WebCodecsで動画の音声を逐次デコード
- 動画ファイル自体はCDNにもGitHubにも送信しない
- 音声を0.25秒ごとに集計して、直前との音量差・ピーク強度を採点
- **音量の上昇のみを検出**。歓声、風、雑談、大声の指示などは区別しません
- iPhone Safariと実際の大型MOV / MP4ファイルでの実機検証はまだ必要です
- Safariを閉じると解析が中断します。解析中はアプリを前面に

## 複数動画版について

- 解析済みのファイルは、さらに動画を追加しても再解析不要。感度を変更した場合は各動画の保存済み音声データから候補を再計算します。
- 選択した見どころだけが結合されます。**元動画を丸ごと連結するモードではありません。**
- 動画ごとに独立した候補時刻を管理し、動画の並び順に従って1つのMP4にします。違う縦横比は先頭の採用動画に合わせて黒帯で収め、引き伸ばしません。
- 音声はAAC・48kHz・2chへ統一します。**音声付き動画のみ**が対象です。動画そのものは端末の外へ送信しません。
- 大きい動画を複数読み込んだ場合、特に高画質の書き出しはiPhone Safariのメモリ制限を受けることがあります。完成動画は当面3分以内です。
- 2026-10-12時点：JavaScriptの構文チェックと単体テストを確認しました。実際のiPhoneで異なる複数MOV/MP4をつないで正常保存できるかは、実機テストが必要です。

## 2026-10-12 第3版

- YouTubeのタイムスタンプは**元の各動画ごとの時刻**。一括一覧と、各動画の「この動画の時刻をコピー」ボタンを用意。

- **各シーン間の映像に0.5秒（30fpsで15フレーム）のクロスディゾルブ**。元音声はその時点で切り替え。
- 冒頭5秒の文字フォントを4種類から選択し、サイズを60〜150%で調整（横幅を超えないよう自動縮小）。
- 構文検査と音量終了位置・素材別時刻・選択状態・トランジション時間の単体テストを実施。実際のiPhone MOV/MP4での最終的な動画・音声出力は別途実機確認が必要。

## 2026-10-13 動画タイムラインの直接編集（v9）

- リプレイ動画直下の切り取り範囲に**白い現在再生位置マーカー**を追加。動画の再生に合わせて時刻（例：`00:12.4`）と白線が動く。VideoFrameCallback利用可能時はフレームごと、その他のブラウザでは`timeupdate`で更新。
- タイムラインの開始・終了を**太いドラッグハンドル**で移動可能に。通常のドラッグは0.25秒単位、**450ms以上長押ししてからドラッグ**すると0.1秒単位で微調整できる。
- タイムライン内をタップしてその位置へシークできる。切り取りの外側へはシークしない。ドラッグ中は指スクロールと誤操作が競合しないよう調整。
- 開始／終了欄は動画の**元時刻**として少数第一位まで直接入力でき、負の時刻は表示・入力不可。以前の「−1秒」「+1秒」ボタンを撤去。キーボード操作は矢印キーで0.25秒、Shift＋矢印で0.1秒。
- 開始・終了のハンドルを動かした結果はタイムスタンプとMP4書き出し範囲に反映。終了を「自動に戻す」も維持。
- モバイルSafari・Android Chromeの実機タッチ挙動は、デプロイ後に確認が必要。

## 2026-10-13 シーンごとの拡大（v10）

- 試合動画内で人物が遠い場合、各シーンのリプレイ動画のすぐ下にある **「映像を拡大（中央）」** から **1倍（通常）・1.5倍・2倍** を選択できます。
- 選んだ拡大率はリプレイの画面表示と完成MP4両方に反映。**元のMOV/MP4を変更・アップロードしません**。
- 画面中央が拡大中心です。端の映像はカットされるため、被写体が中央にいない場面の追尾・位置移動は今回の対象外。
- 動画の音声・切り取り時間・タイトル編集・再生位置・キープ操作は変更しません。
- 設定はシーン単位で保持し、音声感度などを再解析しても同じシーンの倍率を復元。完成済みのMP4はズームを変更した場合に再書き出しが必要です。

## 2026-10-13 拡大率の自由調整（v11）

- 各シーンの拡大設定を **1倍／1.5倍／2倍のドロップダウンから、1.0倍〜3.0倍（0.1倍刻み）のスライダー**へ変更。
- スライダー操作中、現在の倍率（例：2.3倍）を表示し、同時にリプレイ映像に反映。
- 1.7倍など任意の0.1倍刻みの倍率はMP4生成時の中央クロップにも反映。音声・切り取り・タイトルなど既存の編集機能は維持。
- 旧バージョンの拡大設定（1.0／1.5／2.0倍）も有効な範囲のまま利用可能。
- 3倍を超える拡大と画面中心以外を指定するパン／自動追尾は現時点で対象外。大きな拡大は画質劣化が見える場合があります。

## 2026-10-13 ノイズ抑制型の音声解析（v12）

AIなし・外部APIなしで、撮影者の会話、工事の機械音、工具などの衝撃音の誤検出を減らすためのアルゴリズムを追加。

- 従来と同様、まず **0.25秒ごとのRMS音量・音量の急上昇・周囲とのコントラスト** から候補を探す。
- 一度の音声デコード中に、追加で **大まかな低／高音域の比率と鋭い音の指標（crest）** を計算。周波数分析は軽量なフィルターで近似し、別途AIモデル／二度目の動画読み込みは不要。
- 候補をすぐ8件に確定せず、**前後約3.5秒の音量の継続・直後の余韻・断続的な繰り返し・低周波成分**を使って候補を再採点してから件数上限を適用。
- **標準／厳選**は、非常に短い衝撃音、短く断続的な発話のようなパターン、低周波成分が強い工事・エンジン音のようなパターンを抑制。
- **「多めに拾う」では抑制を緩める**。短い歓声などが通常モードで見逃された場合の救済手段として使用。
- 波形、キープ／不採用、切り取り位置、ズーム、MP4の生成、プライバシー仕様は維持。動画・音声のアップロードはなし。

**限界:** これは音の意味を理解する分類器ではありません。近くで叫ぶ撮影者とゴールの歓声、工事現場の音と拍手は依然として混同する可能性があります。背景音が混ざった実際のiPhoneの動画での評価は別途必要。合成波形と信号処理ロジックの単体テストは付属しています。

## 2026-10-14 カスタム5秒イントロ（v13）

従来の5秒のタイトルカードを、ユーザーが選んだ**背景画像・動画と透過PNG**へ差し替えられるイントロ編集機能を追加。

- 背景は「デフォルト」「静止画（JPG/PNG/WebP）」「動画（MP4/MOV）」から選択。
- **デフォルトでは旧デザインのまま**。背景のみ変更した場合は従来の文字タイトルを新しい背景上に描画。
- 透過PNGを選ぶと従来の文字タイトルの代わりに重ねる。9分割プリセット、キャンバス内のドラッグ移動、サイズ20%〜100%の調整が可能。
- 出力対象の最初の動画の縦横比に応じてイントロプレビューを調整し、背景はアスペクト比を保って中央クロップ。PNGはアスペクト比を保持し、画面の外に出ないよう位置を制限。
- 背景動画は最初の5秒を**音声を使わず**フレームごとに描画。背景動画が5秒に満たない場合は最終フレームを保持し、イントロ全体の長さは5秒のまま。
- 画像/PNG背景は1フレームを5秒表示。画像ファイルは25MB以下、透過PNGは10MB以下、動画は300MB以下に制限。
- 素材・PNG位置・サイズ変更時は、前の書き出し結果を無効化。端末のローカルFile/Blobのみを使い、**元素材はアップロード・改変しない**。
- 背景動画を含むiPhone/Android実機での最終MP4エンコード・保存は別途検証が必要。SafariのWebCodecs/コーデック・メモリ制限を受ける。
- PNGと背景はそれぞれローカル選択。再読み込み後の編集内容の永続保存は、このリリースでは対象外。

## 2026-10-14 デフォルト文字タイトルの自由配置（v14）

- 透過PNGを選ばないときの **デフォルト文字タイトル**（GOALS!、HIGHLIGHTS!、自由入力した文字など）も、9か所の位置プリセットとイントロプレビュー内のドラッグ移動に対応。
- 文字のプレビュー・タッチ位置判定・最終MP4書き出しが**同じ文字描画ロジックと正規化座標**を使用。文字が画面端からはみ出さないよう位置を制限。
